# تشغيل PALLCOM MCR عن بُعد

تعمل لوحة الإدارة على خادم له دومين عام. يعمل وكيل MCR على جهاز Windows الذي يشغّل OBS Studio، سواء كان جهازًا محليًا أو خادم بث. يتصل الوكيل بـ OBS محليًا على المنفذ 4455، ويفتح اتصال WSS صادرًا إلى اللوحة عبر المنفذ 443. يرسل OBS البث إلى وجهته المعتادة.

## نشر لوحة الإدارة

1. جهّز خادمًا عليه Docker وDocker Compose. وجّه سجل DNS للدومين إلى الخادم واسمح بالوصول إلى المنفذين 80 و443.
2. جهّز شهادة TLS للدومين وضع ملفي الشهادة والمفتاح باسم **fullchain.pem** و**privkey.pem** في مجلد يستطيع Docker قراءته. أعد تحميل Nginx بعد تجديد الشهادة.
3. أنشئ ملف **.env** في جذر المشروع على خادم اللوحة وأضف القيم التالية. استخدم دومينك ومسار الشهادة الفعليين، واختر كلمة مرور مدير من 12 حرفًا على الأقل. ولّد قيمة مستقلة لكل سر من الأسرار الثلاثة باستخدام الأمر **openssl rand -hex 32**.

   ~~~dotenv
   MCR_PUBLIC_ORIGIN=https://mcr.example.com
   MCR_TLS_DIRECTORY=/absolute/path/to/tls
   MCR_ADMIN_PASSWORD=
   JWT_SECRET=
   REFRESH_TOKEN_SECRET=
   ENCRYPTION_MASTER_KEY=
   ~~~

4. من جذر المشروع على خادم اللوحة شغّل الأمر التالي.

   ~~~sh
   docker compose --env-file .env -f backend/infrastructure/docker/docker-compose.yml up -d --build
   ~~~

5. افتح الدومين في المتصفح. في التثبيت الجديد سجّل الدخول بحساب **admin@mcrpro.local** وكلمة مرور المدير التي عيّنتها. تُحفظ البيانات في SQLite داخل وحدة التخزين **mcr_sqlite** الخاصة بمشروع Compose.

## تجهيز جهاز OBS وتشغيل الوكيل

1. افتح OBS ثم **Tools → WebSocket Server Settings**. فعّل الخادم والمصادقة، واحتفظ بالمنفذ وكلمة المرور. المنفذ الافتراضي 4455 ويُستخدم محليًا على جهاز البث.
2. من لوحة الإدارة، أضف محطة واحفظ منفذ OBS وكلمة المرور. عندما يكون مستخدم جهاز البث جاهزًا، اضغط **إنشاء اقتران** ثم **تنزيل ملف المحطة**. ملف **MCR-Station.json** صالح لمدة خمس دقائق ويُستخدم مرة واحدة.
3. أعطِ مستخدم جهاز البث ملف **MCR-Agent-Windows-x64.exe** وملف المحطة. يضع الملفين في المجلد نفسه ويفتح التطبيق. يبدأ الاقتران تلقائيًا ويعمل الوكيل في الخلفية. يحتوي التطبيق على Node.js وتبعيات الوكيل.
4. بعد إعادة تشغيل الجهاز، يفتح المستخدم OBS ثم التطبيق نفسه. يحتفظ التطبيق بإعدادات المحطة لاستخدامها في التشغيل التالي. لإعادة الاقتران، ضع ملف محطة جديدًا بجانب التطبيق وافتحه.

لبناء التطبيق على جهاز التطوير، جهّز التبعيات باستخدام **npm ci** مع Node.js ‏x64، ثم نفّذ **backend/agent/windows/build.ps1** من PowerShell. ينتج الملف التنفيذي في مجلد **dist**.
