# Application update and rollback

1. Record current immutable images, schema versions, worker protocol, enabled channel identities, active schedules and provider grant revisions. Back up MySQL and the media manifest to protected locations and verify a restoration to an isolated target. Protect credential material separately. Use the same persistent media and database volumes when updating containers.
2. Rehearse on isolated staging. Apply compatible expand migrations first, allow old and new readers through the transition, deploy the API first with old workers still carrying output, and independently verify playback, authorization, queue and state reconciliation. Roll one worker/channel at a time with fencing and an independent receiver. Use tested drain or handoff only. Confirm whether a proposed release can meet the agreed interruption budget before selecting a window.
3. Check receiver identity, frame/audio continuity, service health and provider authorization after every step. Stop on any security failure, unexplained output gap or missing metadata. With schema compatibility intact, return the failed service to the previous image while retaining volumes. Revert incompatible data changes via the approved snapshot and replay process, with explicit handling of new schedules and media references. Never restore into the active location untested.
4. Sign off checks for media files, accounts, schedules, channel settings, IPTV identity, provider grants and secrets after update and rollback. Retire compatibility code and snapshots only after their separately approved retention periods. Preserve historical output and recovery evidence.

During a point-in-time restore, reconcile security changes made after the snapshot before exposing management or playback traffic. Reapply account disables, session and Agent revocations, and provider and graphics link changes. When reconciliation is incomplete, invalidate the affected credentials under the approved recovery procedure and confirm that they are rejected. Verify that the recovered workers can still deliver to the independently authorized receivers.
