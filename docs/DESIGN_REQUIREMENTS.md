# Design requirements

Phase 17 is a mandatory owner approval gate. It opens only after Phase 16 functional verification. Until then, retain the existing design system and limit earlier phase UI changes to necessary functional controls.

At Phase 17, request owner-supplied screens, files, Figma, reference website or brand guidelines. Analyze visual language, color, type, spacing, component states, dashboard layout and navigation patterns. Present the proposed information architecture and implementation plan. Stop and record explicit approval of the reference and proposal before Phase 18. No final visual identity has been selected in Phase Zero.

Verify Arabic/English and RTL/LTR, keyboard focus, contrast, responsive layouts, distinct Preview and Program, visible control scope, status and accessible broadcast confirmations. Validate the implemented design against the approved reference only after authorization.
