# User guide

For the current local workflow, select a station in Live Control, enable Program as station manager if required, upload or select a short MP4, preview it, start Program and take it to air. Use Sources and Scenes for reusable scenes and native scheduling. Audio Mixer and Graphics contain their respective controls.

The independent video upload is limited to 128 MiB and 60 seconds. The IPTV section displays the available URL. A dashboard playback link requires the authorized session. Operators may issue a separate signed link for a supported player for the current Program session. Its one-hour lifetime can end sooner if the session is revoked or Program stops. A localhost URL is reachable only on the same host.

OBS Agent workflows are available under the OBS integration group where configured. For operator handover and startup procedures, see the [staging operator guide](STAGING_OPERATOR_GUIDE.md) and [operations runbook](OPERATIONS_RUNBOOK.md).
