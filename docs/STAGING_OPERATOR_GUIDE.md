# Staging operator quick guide

**Start Program.** On the opted-in staging station, open **Live Control → Independent Program → Start Program**. Open a single receiver on the worker host, for example `ffplay udp://127.0.0.1:5102` when using the default output port. Read the actual port in Live Control. Confirm both picture and audio at that receiver. The initial slate carries silence. Independent Program and OBS stream/record have separate start and stop buttons.

**Take a source or scene.** Independent Program currently offers **Take OBS** and **Take slate**. For OBS, send H.264/AAC MPEG-TS from the approved station-local contribution profile to the worker's loopback input, wait for **Ready**, then take it and check the receiver. For a scene already composed in OBS, the paired Agent and OBS Studio Mode enable the existing Preview scene selection and Cut/Auto controls. That scene reaches independent Program through the selected OBS contribution. Independent file/image scene creation, URL scene Preview and URL takes are unavailable in this build.

**Manage the watermark.** Open **Program watermark**, select the station logo or upload a PNG, JPEG or WebP, enable it and set its size, corner, insets and opacity. Check Preview, choose **Apply to Program**, then inspect a receiver frame. To remove it, clear Enable and Apply. Applied settings survive a service restart.

**Manage ads.** Open **Ad placements**. Add image or MP4 creatives to the library, create placements and append creatives to each playlist. Set each rectangle and layer, then the display, gap, fade and movement per item. Enter scheduled windows in the selected IANA time zone. Review overlap outlines, enable the desired placements and choose **Apply ads to Program**. Use each placement's Pause, Resume, Skip or Disable now controls during operation. Gaps reveal the lower layers. The global watermark draws above all ads.

**Recover a source.** Signal loss on a selected OBS contribution takes the configured slate and silence automatically. Let the returning signal stabilize for five seconds, then take OBS explicitly. A healthy connection can still carry black/silent content when an OBS file is missing. Take slate manually, restore the asset, verify OBS Preview and audio, then retake. For a missing ad creative, disable or skip the affected placement, import a replacement and apply the revised playlist. Other placements can stay on air.

**Recover delivery or the service.** Local Program running status reports encoder activity. UDP provides no downstream receipt acknowledgement. For a blank receiver, check that it is on the worker host and bound to the configured output port, then reopen it. Keep input and output ports distinct. If Program start rejects a port conflict, correct the server configuration, restart the control service and start Program. After a service restart, check saved watermark, playlists, overrides and station selection, start Program explicitly and verify the new session at the receiver. A receiver outage or service restart can leave a gap in its recording.
